# Interaktive Widgets zu Ingenieurmechanik 1

Begleitmaterial zu Sayir, Dual, Kaufmann, Mazza: *Ingenieurmechanik 1* (ETH Zürich).
Die Seiten werden über GitHub Pages ausgeliefert und in Notion eingebettet.

| Widget | Kapitel | Datei |
| --- | --- | --- |
| Kinemate, Invarianten und Zentralachse (3D) | 3.5 | `kinemate-3d.html` |
| Momentanzentrum einer ebenen Bewegung (2D) | 3.6 | `momentanzentrum.html` |

Jede Datei ist eigenständig (HTML, CSS und JavaScript in einer Datei, keine Abhängigkeiten).
Ein Beispiel lässt sich direkt per URL wählen, z. B. `kinemate-3d.html?preset=zp23`.
