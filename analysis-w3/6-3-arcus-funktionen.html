Arcus-Funktionen: sin, cos, tan einschränken und umkehren

sin auf [−π/2, π/2] → arcsin : [−1, 1] → [−π/2, π/2]. cos auf [0, π] → arccos : [−1, 1] → [0, π]. tan auf (−π/2, π/2) → arctan : ℝ → (−π/2, π/2). Eine andere Einschränkung liefert eine andere Umkehrfunktion.
